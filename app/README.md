MD Tracker

MD Tracker — Android-приложение для самоконтроля и анализа малоадаптивной мечтательности (Maladaptive Daydreaming).
Проект помогает пользователям осознавать, измерять и постепенно снижать частоту и интенсивность эпизодов непроизвольного фантазирования.


📌 О проблеме

Малоадаптивная мечтательность (MD) — это не просто «витание в облаках», а поведенческая зависимость, при которой человек теряет часы, уходя в детализированные фантазии. Это вызывает чувство стыда, тревогу, снижает продуктивность и качество жизни.

MD Tracker превращает бессознательную привычку в управляемый процесс, предоставляя объективные данные и аналитику.


✨ Основные возможности

· Регистрация и аутентификация — безопасный вход с сохранением сессии.
· Диагностический тест — скрининг на основе валидированного опросника MDS-SF5 с определением уровня (низкий / средний / высокий).
· Главный экран (Dashboard) — сводка за сегодня: количество эпизодов, общая длительность, быстрый доступ к логу.
· Быстрый лог — фиксация эпизода в 2 касания: длительность, интенсивность (1–10), триггер, заметка.
· График прогресса — визуализация динамики частоты и интенсивности за неделю/месяц.
· ИИ-помощник (аналитика) — автоматические отчёты каждые 7–14 дней с выявлением паттернов и трендов.
· Профиль — информация о пользователе, результаты последнего теста, возможность пройти тест заново.



🛠️ Технологический стек

· Язык: Kotlin
· Архитектура: MVVM (ViewModel + LiveData/Flow)
· База данных: Room (локальное хранение)
· Асинхронность: Coroutines
· Навигация: Navigation Component (Single Activity)
· Графики: MPAndroidChart
· Планировщик: WorkManager (для периодических отчётов)
· UI: Material Components, ViewPager2, BottomNavigationView



🚀 Установка и запуск

1. Клонируйте репозиторий:
   bash
   git clone https://github.com/diyora-eng/md-tracker.git

2. Откройте проект в Android Studio (версия Arctic Fox или новее).
3. Дождитесь синхронизации Gradle.
4. Запустите приложение на эмуляторе (API 29+) или физическом устройстве.

Примечание: Для работы уведомлений и фоновых задач необходимо разрешить приложению доступ к уведомлениям.


📱 Как это работает

1. Осознание — при каждом эпизоде пользователь открывает приложение и фиксирует данные. Это переключает мозг из режима фантазии в режим наблюдения.
2. Измерение — цифры и графики показывают реальную картину, а не субъективные ощущения.
3. Анализ — ИИ-помощник находит закономерности: время, триггеры, среднюю длительность.
4. Коррекция — на основе отчётов пользователь меняет рутину, убирает триггеры, ставит микро-цели.
5. Подкрепление — прогресс на графиках даёт реальный дофамин, замещая фантазийный.
